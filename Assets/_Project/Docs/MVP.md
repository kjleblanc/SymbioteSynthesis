# MVP Feature Set (MoSCoW)

## Must (4–8 weeks)
- Hex board; sticky pieces; drag-merge.
- FusionService with “2+2=3” + cross-color outputs.
- Three merges/turn rule; turn controller.
- Basic traits: Rending, Armored.
- Combat on same board (initiative/tick).
- SpawnDirector with pity/anti-dup.
- WaveDirector with 10 waves + 2 elites.
- Discovery tab (run + meta persistence).
- Branching map (8–12 nodes).
- Results screen with run summary.

## Should
- Colorblind modes; basic remap.
- Damage numbers; simple merge VFX.
- Seed input at run start.

## Could
- Simple events; 1–2 map modifiers.
- Basic telemetry (local file).

## Won’t (MVP)
- Multiplayer; mobile; meta-currencies; 3D; URP 2D lights; Addressables/Localization; Cinematics.
